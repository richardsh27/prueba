# prueba

Mi primer proyecto en GitHub: una página web básica.

## Qué contiene

- `index.html`: la página (HTML, CSS y un poco de JavaScript en un solo archivo).
- `README.md`: este archivo, que GitHub muestra como portada del repositorio.

## Cómo verla

Descarga `index.html` y ábrelo con doble clic en tu navegador, o visita la versión publicada con GitHub Pages:
https://richardsh27.github.io/prueba/

## Conceptos básicos de Git y GitHub

- **Repositorio**: la carpeta del proyecto con todo su historial de cambios.
- **Commit**: una "foto" de tus archivos en un momento dado, con un mensaje que dice qué cambió.
- **Rama (branch)**: una copia paralela donde pruebas cambios sin tocar la versión principal (`main`).
- **Pull request**: una propuesta para unir los cambios de una rama a `main`.
- **Merge**: aceptar esa propuesta y unir los cambios.
